# Buscaminas

Un **Buscaminas simple hecho con JavaScript** como proyecto de práctica para mejorar mis habilidades con JavaScript, manipulación del DOM y lógica de programación.

## Descripción

El objetivo del juego es descubrir todas las casillas que no contienen minas sin hacer clic sobre una mina.

El proyecto está desarrollado utilizando **HTML, CSS y JavaScript**, sin frameworks ni librerías externas.

## Funcionalidades

* Generación de un tablero de Buscaminas.
* Minas colocadas aleatoriamente.
* Contador de minas cercanas en cada casilla.
* Detección de victoria y derrota.
* Interacción con el tablero mediante clics.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
